# Career Compass AI

Build a production-ready AI-powered Career Guidance Platform called "CareerCompass AI".

The design should be inspired by the uploaded dashboard image but should NOT copy it exactly. Make it more modern, professional, clean, premium, responsive, and suitable for a real-world SaaS application.
